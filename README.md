# 🏴‍☠️ One Piece Dle

A One Piece character guessing game inspired by Wordle, with 6 different game modes.

🔗 **Play it here:** https://stav-ba.github.io/one-piece-dle/

---

## 🎮 Game Modes

| Mode | Description |
|------|-------------|
| ⚔️ **Classic** | Guess the character from attribute comparison hints (gender, affiliation, bounty, sea, arc, haki, devil fruit, status) |
| 🔍 **Description** | 4 physical clues revealed one by one (height, skin, hair, distinctive feature) |
| 🎯 **Stats** | Bounty shown first — wrong guesses reveal devil fruit type, sea, haki, and affiliation |
| 👤 **Silhouette** | Real character image blurred into a shadow — progressively unblurs with each wrong guess |
| 👥 **Crew** | See known crew members, guess the mystery hidden member |
| ⚡ **Ability** | 4-clue Devil Fruit ability description — last clue names the fruit itself |

---

## 📦 Tech Stack

- Pure HTML/CSS/JavaScript — single file, no framework, no build step
- Background pixel art wallpaper embedded as base64
- Character images loaded from [Jikan API](https://jikan.moe/) (MyAnimeList)
- Hosted on GitHub Pages (free)

---

## 📊 Character Database

300+ One Piece characters with the following attributes:
- Name, Gender, Affiliation & Affiliation Type
- Devil Fruit Type, Bounty, Sea of Origin
- Status (Alive/Deceased), First Arc Appearance, Haki types
- Physical description (height/build, skin tone, hair, distinctive features)
- Devil Fruit ability descriptions (for 35+ major fruit users)

---

## 🚀 Run Locally

No build step needed — just open `index.html` in a browser.

```bash
git clone https://github.com/Stav-BA/one-piece-dle.git
cd one-piece-dle
open index.html
```
